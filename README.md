**GAIA Landslide Predictor** is the **Physics-Informed Deep Learning & Early Warning Subsystem** of the **GAIA Ecosystem**. It combines a **Spatio-Temporal Physics-Informed Neural Operator (ST-PINO)** with traditional machine learning benchmarks (XGBoost & Random Forest) to perform real-time slope stability risk assessment.

> 🔗 **Related Project**: This prediction engine consumes environmental hazard datasets generated by our automated multimodal ingestion tool, [**GAIA PDF Data Pipeline**](https://github.com/benAJoseph/GAIA_PDF_Data_Pipeline).

## 🌟 Key Features

1. **Spatio-Temporal Physics-Informed Neural Operator (ST-PINO)**:
   - 🧠 **Hydrological Expert**: Bi-LSTM for sequential rainfall accumulation & soil moisture temporal dynamics.
   - 🗺️ **Geotechnical Expert**: Graph Convolutional Network (GCN) for spatial terrain topology & slope proximity modeling.
   - 🌲 **Land Use Expert**: Transformer Multi-Head Self-Attention for land cover and vegetation dynamics.
   - ⚖️ **Physics Layer**: Differentiable Mohr-Coulomb Factor of Safety ($FOS$) calculation grounding predictions in slope stability physics.
2. **Live Environmental API Integration**:
   - Geocoding via OpenStreetMap Nominatim.
   - Live & historical daily rainfall and soil moisture via Open-Meteo API.
   - Elevation lookup via Open-Elevation API.
3. **Multi-Model Benchmark Comparison**:
   - Compares deep learning ST-PINO predictions directly against trained XGBoost & Random Forest models.
4. **Interactive Geospatial Dashboard**:
   - Built with Streamlit, dark glassmorphism aesthetic UI, Folium maps, Plotly risk gauges, and physical stability indicators.

## 📐 Physical Grounding: Factor of Safety ($FOS$)

Unlike purely empirical "black-box" machine learning models, **GAIA** enforces physical consistency by integrating the **Mohr-Coulomb limit equilibrium equation** directly into neural attention gating:

$$FOS = \frac{c' + (\gamma h \cos^2\beta - u) \tan\phi'}{\gamma h \sin\beta \cos\beta}$$

Where:
- $c'$: Effective soil cohesion ($kPa$)
- $\gamma h$: Soil column unit weight $\times$ depth ($kN/m^2$)
- $\beta$: Slope inclination angle ($^\circ$)
- $u$: Pore water pressure ($kPa$) driven by soil moisture
- $\phi'$: Effective internal friction angle ($^\circ$)

### Stability Categorization:
- **$FOS < 1.0$**: Slope Failure Imminent (**Critical / High Risk**)
- **$1.0 \le FOS < 1.5$**: Marginally Stable (**Moderate Warning**)
- **$FOS \ge 1.5$**: Stable Slope (**Low Risk**)

## 🛠️ Quickstart Installation

### 1. Clone Repository & Navigate:
```bash
git clone https://github.com/benAJoseph/GAIA_Landslide_Predictor.git
cd GAIA_Landslide_Predictor
```

### 2. Install Dependencies:
```bash
pip install -r requirements.txt
```

### 3. Launch Interactive Dashboard:
```bash
streamlit run app.py
```
